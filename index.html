Eureka_Utils

Utilidad portable para configurar, auditar y diagnosticar equipos Windows 11, de uso personal y profesional.

Descargar la última versión Código en GitHub

Qué hace

  • Hardware: identifica el equipo (modelo, número de serie, Machine Type de Lenovo, Service Tag de Dell...), detecta CPU, RAM, discos, red y tarjeta gráfica (NVIDIA, AMD o Intel), mide el consumo real de memoria y comprueba la compatibilidad con Windows 11.
  • Drivers y BIOS: todo el hardware con su controlador, controladores y firmware desde Windows Update, versión de la BIOS y requisitos de juegos (TPM 2.0, UEFI y arranque seguro).
  • Software: catálogo con dependencias e impacto en disco y RAM, e instalación y actualización con winget.
  • Bloatware: quita las apps preinstaladas indicando el riesgo de cada una, y permite reinstalarlas.
  • Perfiles: Personal, Oficina (Microsoft 365), Oficina IT, Gaming, Gaming + Streaming, Creativo, Desarrollo, Estudiante y Equipo básico.
  • Cuentas y dominio: cuentas locales, Active Directory, Microsoft Entra ID con verificación en dos pasos, Intune, unión híbrida y hash de Autopilot.
  • Diagnóstico y antivirus: SFC, DISM, CHKDSK, Microsoft Defender y Microsoft Safety Scanner portátil.
  • Cada aviso explicado: un icono ⓘ en cada comprobación con aviso o fallo explica a qué se debe y cómo solucionarlo, y prepara un informe para preguntar a la IA que elijas (Claude, Copilot, ChatGPT, Gemini...).
  • Tareas en paralelo: consulta el hardware o analiza el sistema mientras se instalan o actualizan aplicaciones.
  • USB de instalación: instala Windows 11 y deja el equipo configurado automáticamente.
  • Idiomas: español, English, Français, Português, Euskara, Català, Valencià y Galego, en modo claro u oscuro.

Cómo empezar

  1. Descarga Eureka_Utils_Portable.exe desde la página de la última versión y, si quieres, comprueba su huella SHA-256 (está en las notas de cada versión).
  2. Ejecútalo y acepta el aviso de administrador. Si Smart App Control bloquea el .exe, usa Eureka_Utils.cmd desde el código fuente.
  3. Espera a que termine la detección, elige un perfil y revisa la selección antes de aplicar.

Toda acción que modifica el equipo pide confirmación y se puede crear un punto de restauración antes de aplicarla.

Firma de código

Los ejecutables todavía no están firmados digitalmente, así que Windows puede mostrar «Editor desconocido» y Smart App Control puede bloquearlos; en ese caso usa Eureka_Utils.cmd desde el código fuente. Cada versión publica la huella SHA-256 de sus archivos para comprobar que no se han alterado.

Está previsto firmarlos con SignPath Foundation, que firma gratis proyectos de código abierto con cierta difusión. Si Eureka_Utils te resulta útil, darle una ⭐ en GitHub o compartirlo ayuda a conseguirlo. Consulta la política de firma de código y la política de privacidad.
